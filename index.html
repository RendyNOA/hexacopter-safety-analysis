Data that is not available yet stays an open item, not a guess.

Compare layouts at the current settings

More rotors is not automatically safer: a classic PNPNPN hexacopter cannot stay fully controllable after any single rotor loss, so its six ESCs act as six single points of failure. In the PPNNPN layout one failure of rotors 1–4 is tolerable — if the flight software detects it and re-allocates control (requirement SR-02).

λp = N · λg · πQ, failures per 106 h, environment ARW (airborne, rotary winged). Parts count treats every part as critical, so the result is an upper bound for this hazard. Every λg and πQ was checked line by line against MIL-HDBK-217F Notice 2, Appendix A (pages A-2 to A-11).
